## 用語集の使い方

麻雀にはたくさんの専門用語があります。記事やドリルでわからない言葉が出てきたら、ここで確かめてください。
くわしい説明がある言葉には、記事へのリンクをつけています。

## 基本

| 用語 | 意味 |
| --- | --- |
| 半荘 | 東1局〜南4局までの1回の対局(東南戦) |
| 局 | 配牌からアガリ・流局までの1回 |
| 親・子 | 親は1人で点数が1.5倍。残り3人が子 |
| 連荘 | 親が続けて親をすること |
| 配牌 | 最初に配られる13枚 |
| ツモ | 山から牌を引くこと。自分で引いてアガること |
| ロン | ほかの人の捨て牌でアガること |
| 河 | 捨て牌を並べる場所 |
| 王牌 | ツモに使わない14枚。ドラ表示牌がある |
| 上家・下家・対面 | 左隣・右隣・向かいの人 |
| 流局 | 誰もアガらずに局が終わること |
| オーラス | 最後の局(南4局)。[オーラスの考え方](/learn/all-last) |

## 牌と形

| 用語 | 意味 |
| --- | --- |
| 萬子・筒子・索子 | 1〜9の数牌の3種類 |
| 字牌 | 東南西北(風牌)と白發中(三元牌) |
| 么九牌 | 1・9・字牌 |
| 中張牌 | 2〜8の数牌 |
| 面子 | 順子(続いた3枚)か刻子(同じ3枚) |
| 雀頭 | アガリ形の同じ牌2枚 |
| 対子 | 同じ牌2枚 |
| ターツ | あと1枚で順子になる2枚 |
| 孤立牌 | どこにもつながっていない牌 |
| シャンテン数 | テンパイまであと何枚か |
| テンパイ | あと1枚でアガれる状態 |
| 受け入れ枚数 | 手が進む牌の残り枚数。[受け入れ枚数とは](/learn/ukeire) |
| 良形・愚形 | 待ちの多い形・少ない形。[良形と愚形](/learn/good-shape) |

## 待ち

| 用語 | 意味 |
| --- | --- |
| 両面 | 23で1と4を待つ形。最大8枚。[待ちの種類](/learn/waits) |
| 嵌張 | 13で2を待つ形 |
| 辺張 | 12で3、89で7を待つ形 |
| 双碰 | 対子2組のどちらかを待つ形(シャンポン) |
| 単騎 | 1枚の相方を待つ形 |
| ノベタン | 1234で1と4を待つ形 |
| 多面張 | 3種類以上を待つ形 |
| 形式テンパイ | 役がなくても形がテンパイ。流局時はテンパイ扱い |

## 手役・鳴き

| 用語 | 意味 |
| --- | --- |
| 役 | アガリに必要な条件。1つ以上必要(一翻縛り) |
| 門前 | 鳴いていない状態 |
| 鳴き | ポン・チー・カンで牌をもらうこと |
| 喰いタン | 鳴いてタンヤオ。Mリーグはあり |
| 後付け | 鳴いたあとで役をつけること。Mリーグはあり |
| 喰い替え | 鳴いた牌と同じ・スジの牌を切ること。禁止 |
| 食い下がり | 鳴くと1翻下がる役 |
| ダマ | リーチせずにテンパイすること |
| ドラ | 1枚1翻増える牌。役ではない |
| 裏ドラ | リーチしてアガった人だけが見られるドラ |
| 赤ドラ | 赤い5。各色1枚 |
| 役満 | 最高の役。子32,000点・親48,000点 |
| 一発 | リーチ後1巡以内のアガリでつく1翻 |
| 役牌 | 白・發・中・自風・場風。3枚で1翻 |
| オタ風 | 自風でも場風でもない風牌。役にならない |
| パオ | 大三元などを確定させる鳴きをさせた人が払う責任払い |

## 守備

| 用語 | 意味 |
| --- | --- |
| 放銃 | ロンされること(振り込み) |
| フリテン | 待ち牌を捨てていてロンできない状態。[フリテン](/learn/furiten) |
| 現物 | リーチした人の河にある、絶対に当たらない牌 |
| スジ | 1-4-7などの3つ離れた牌。両面待ちに当たらない |
| 壁 | 4枚見えていて、その牌を使う両面待ちがない状態 |
| ノーチャンス | 壁があって両面待ちで当たらない牌 |
| 無スジ | スジも壁もない、危ない牌 |
| ベタオリ | 安全な牌だけを切って降り切ること。[ベタオリの手順](/learn/betaori) |
| 押し引き | 勝負するか降りるかの判断。[押し引きの考え方](/learn/pushfold) |
| 頭ハネ | 2人が同時にロンしたとき、放銃者の下家から近い1人だけがアガること |

## 点数

| 用語 | 意味 |
| --- | --- |
| 翻 | 役とドラの数。1つ増えると点数がおよそ2倍 |
| 符 | 形とアガリ方の点。[符計算](/learn/fu) |
| 満貫 | 5翻(または切り上げ満貫)。子8,000点・親12,000点 |
| 切り上げ満貫 | 30符4翻・60符3翻を満貫にすること。Mリーグはあり |
| 本場 | 積み棒。1本300点 |
| 供託 | 場に出ているリーチ棒。次にアガった人のもの |
| ノーテン罰符 | 流局時にノーテンの人が払う。場に3,000点 |
| 基本点 | 符×2の(翻+2)乗。子のロンはこの4倍、親は6倍 |
| 跳満・倍満・三倍満 | 6〜7翻・8〜10翻・11翻以上の点数 |
| 順位点 | 順位でもらうポイント。+50/+10/−10/−30 |

点数の数え方は[点数計算の基本](/learn/score-basics)、ルールの全体は[Mリーグルールの特徴](/learn/mleague-rules)で説明しています。
