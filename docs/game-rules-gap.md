# CPU対戦のルールと majiang-core の違い

CPU対戦(`/play`)の対局の進行は `@kobalab/majiang-core`(MIT)を使います。
ライブラリのルール設定(`src/game/rule.ts`)を Mリーグ公式ルール(`docs/rules.md`)に合わせ、設定で合わせられないところは自前で計算・補正しています。

## 1. 設定で合わせた項目

| 項目 | ライブラリの初期値 | このサイトの設定(Mリーグ) |
| --- | --- | --- |
| 連風牌の雀頭 | 4符 | 2符(`連風牌は2符`) |
| 途中流局(九種九牌・四風連打・四家立直・四槓散了) | あり | なし |
| 流し満貫 | あり | なし |
| 同時ロン | ダブロンあり | 頭ハネ(`最大同時和了数: 1`。放銃者の下家 → 対面 → 上家の順) |
| 連荘 | テンパイ連荘 | テンパイ連荘(同じ) |
| トビ終了 | あり | なし |
| オーラス止め(アガリやめ) | あり | なし |
| 延長戦(西入) | サドンデス | なし |
| カンドラ | 後乗せ | すぐめくる |
| ツモ番のないリーチ | なし | あり(海底をツモった人は不可。下の 3) |
| リーチ後の暗槓 | 待ちが変わらなければ可 | 面子構成(牌姿)が変わらなければ可(`リーチ後暗槓許可レベル: 1`) |
| ダブル役満(四暗刻単騎・国士十三面など) | あり | なし(役満の複合はあり) |
| 数え役満 | あり | なし |
| 切り上げ満貫 | なし | あり(30符4翻・60符3翻は満貫) |
| 赤ドラ・喰いタン・喰い替え禁止・一発・裏ドラ・カンドラ・カン裏・パオ(大三元・大四喜) | Mリーグと同じ | そのまま |

暗槓に対する搶槓(国士無双を含む)は、ライブラリでも受け付けないので Mリーグと同じです。人和・流し満貫もありません。

## 2. 自前で計算する項目(`src/game/result.ts`)

ライブラリの終局処理は使わず、次のとおり計算し直します。

| 項目 | ライブラリ | Mリーグ(このサイト) |
| --- | --- | --- |
| 順位点 | 設定した値(返し30,000点が前提ではない) | (持ち点 − 30,000)÷ 1,000 + 順位点 +50/+10/−10/−30 |
| 同点の順位 | 起家に近い人を上の順位にする | 同じ順位にして、順位点を等分(端数は起家に近い人が多く受け取る) |
| 南4局流局時のリーチ棒 | 起家に近い順で1位の人へ全額 | トップが取得。トップが同点なら按分(端数は起家に近い人へ) |

## 3. 補正している項目

| 項目 | ライブラリ | 補正 |
| --- | --- | --- |
| 海底をツモった人のリーチ | 「ツモ番なしリーチあり」にすると、残り0枚でもリーチできる | 残り0枚ならリーチ不可にする(`applyMleaguePatches`)。ゲームの進行と CPU の両方に効く |
| 四槓子のパオ | パオの対象は大三元・大四喜だけ | 大明槓で4つ目のカンをしたとき、鳴かせた人を記録し(`Game.fulou` を包む)、四槓子でアガったら責任払いにする |
| パオのロンでの積み棒 | 放銃者が払う | 責任払いのアガリは点数の動きを計算し直し、積み棒は責任者が払う(`src/game/pao.ts`。ツモは全額・ロンは折半・複合した役満の残りはふつうのツモ/ロン) |
| 流局時の4枚使いのテンパイ | 手牌(副露を除く)で4枚使っている牌だけを待ちから外す | 流局の判定の間だけ、副露も含めて4枚使っている当たり牌を待ちから外す(`pingjuTingpai`)。例: 1萬をポンしていて1萬単騎はノーテン |

テストは `src/game/pao.test.ts`。

## 4. 再現できていない項目(まれな場面)

| 項目 | ライブラリ | Mリーグ | 影響 |
| --- | --- | --- | --- |
| 責任払いが2人いるアガリ | 責任払いは1つの役満だけ | 大三元と四槓子で別々の人が責任者なら、それぞれの分を払う | 2つの役満の責任払いが同時に起きることはほぼない。最初に見つかった1つだけを責任払いにする |

## 5. 点数の突き合わせ(自前エンジン `scoring.ts` と majiang-core)

`src/game/scoringCrosscheck.test.ts` で、同じアガリを両方で計算して比べています。

| 比べたもの | 件数 | 食い違い |
| --- | --- | --- |
| 点数計算ドリルの問題作りで作ったランダムなアガリ形(初級・中級・上級) | 3,000件 | 0件 |
| 点数計算のテストケース集(`scoring.cases.ts`。役満15件・カン・海底・嶺上・搶槓・本場などを含む。天和・地和の2件を除く) | 78件 | 0件 |

翻・符・点数(本場・供託を除く)がすべて一致しました。自前エンジンを直した箇所はありません。
比べ方が正しく働くことは、わざと点数を1点ずらすとすべて食い違いになることで確かめています。
