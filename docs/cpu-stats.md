# CPU の成績(自動対局)

`npm run cpu:selfplay` で CPU 4人の半荘を自動で回した結果です(Mリーグルール。牌山はシード 1〜N で固定)。

## CPU: majiang-ai 最新版(1000半荘・2026-10-19)

- 実行: 4並列で約93.4分。エラー・無限ループ: なし
- 局数: 11391局(1半荘あたり 11.4局)

| 項目 | 全員の平均 |
| --- | --- |
| 和了率 | 21.4% |
| 放銃率 | 12.9% |
| 立直率 | 23.5% |
| 副露率 | 34.3% |
| 平均打点 | 5,686点 |
| 平均順位(プレイヤーごと。起家は半荘ごとにランダム) | P1 2.49・P2 2.47・P3 2.51・P4 2.52 |


### 読み方

- 4人とも同じ CPU なので、平均順位はどのプレイヤーもほぼ 2.5 になります(差は偶然のばらつきの範囲)。
- 和了率・放銃率・立直率・副露率は「局のうち、その出来事があった割合」です(1人あたり)。
- 平均打点は、アガリ1回あたりの点数(本場・供託を含まない)です。
