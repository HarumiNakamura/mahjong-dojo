# CPU の成績(自動対局)

`npm run cpu:selfplay` で CPU 4人の半荘を自動で回した結果です(Mリーグルール。牌山はシード 1〜N で固定)。

## 難易度の強さの差(まとめ)

CPU対戦の難易度ごとに、**「つよい」CPU 1人 + その難易度の CPU 3人** で 1,000半荘ずつ打たせ、「つよい」の平均順位で強さを比べました。
相手が弱いほど「つよい」の順位は良く(小さく)なります。4人とも同じ強さなら 2.50 です。

| 難易度(相手の CPU 3人) | 中身 | 「つよい」の平均順位 | 「つよい」の1位率 |
| --- | --- | --- | --- |
| やさしい | 受け入れ枚数が最大の牌を切るだけ。守備・鳴き・リーチなし(`src/game/easyPlayer.ts`) | 1.40 | 75.2% |
| ふつう | majiang-ai の古い版(legacy 0201) | 2.33 | 30.8% |
| つよい | majiang-ai 最新版 | 2.49(4人とも同じ CPU) | — |

- 1,000半荘の平均順位のばらつき(標準誤差)は約0.035なので、3段階の差ははっきりしています。
- 調整の記録: はじめは「やさしい」もテンパイでリーチしていましたが、100半荘で「つよい」の平均順位が 2.09 と「ふつう」(2.17)に近すぎたため、リーチしないようにしました。
  「ふつう」は legacy 0301(200半荘で 2.41)・0401(2.48)も試しましたが、「つよい」との差が小さいため 0201 にしました。

### 読み方

- 4人とも同じ CPU なので、平均順位はどのプレイヤーもほぼ 2.5 になります(差は偶然のばらつきの範囲)。
- 和了率・放銃率・立直率・副露率は「局のうち、その出来事があった割合」です(1人あたり)。
- 平均打点は、アガリ1回あたりの点数(本場・供託を含まない)です。
