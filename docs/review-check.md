## 修正したこと

1. **読み仮名**:漢字だけの用語の初出57か所に読み仮名を付けた。読みは用語データではなく、その語の読みにした(例:暗刻はアンコー、四暗刻単騎はスーアンコータンキ、混全帯么九はチャンタ)
2. **用語のテスト**:`src/content/articles.test.ts` に「用語は初出だけに付け、漢字だけの用語には初出で読み仮名を付ける」を追加した(複合語は語全体の後ろに読みを付ける)
3. **鳴きの記事**:「鳴いた直後に次の牌を切ることはできません」→「鳴いた直後に、鳴いた牌と同じ牌や、そのスジの牌を切ることはできません」
4. **ベタオリの記事**:流局の用語が2回付いていたので、2回目を普通の文字にした

## 気づいたが、そのままにしたこと(小さなもの)

- `noindex` のページ(`/q/…`・`/records/review/…`・`/play/stats` など)には canonical がない。検索に出さないページなので問題はない(og:url はある)
- `/dev/tiles`・`/dev/drill`(確認用ページ)は本番にもある。`noindex` でサイトマップにも載せていない
- 記事の中の複合語(「門前清自摸和」「四暗刻単騎」)は、用語部品が語の一部だけにかかっている
