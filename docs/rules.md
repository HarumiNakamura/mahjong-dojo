# 麻雀道場 採用ルール(Mリーグ公式ルール準拠)

このサイトの問題・判定・点数計算は、すべてこのルールにもとづきます。
プログラム側の設定値は `src/engine/rules.ts` の1か所にまとめています。ルールを変えるときは、このファイル・`src/engine/rules.ts`・`CLAUDE.md` の3か所をそろえて更新してください。

---

## 1. 基本

| 項目 | 内容 |
| --- | --- |
| 人数 | 四人麻雀 |
| 対局の長さ | 東南戦(半荘)。東1局〜南4局 |
| 西入 | なし(南4局で必ず終わる) |
| 持ち点 | 25,000点持ち・30,000点返し |
| トビ | なし(持ち点がマイナスになっても南4局まで続ける) |
| 赤ドラ | 5萬・5筒・5索 が各1枚(計3枚) |

## 2. アガリの条件

- **一翻縛り**:役が1つ(1翻)以上ないとアガれません。
- **ドラは役ではない**:ドラだけではアガれません。役が1つ以上あるときに、翻数を増やすだけです。
- **喰いタンあり**:鳴いていても断么九(タンヤオ)が成立します。
- **後付けあり**:鳴いた時点で役が確定していなくても、アガったときに役があれば有効です。
- **喰い替えは禁止**:鳴いた直後に、鳴いた牌と同じ牌や、筋が同じ牌(例:4・5萬で3萬をチーして6萬を切る)を捨てることはできません。

## 3. ドラ

| 種類 | 内容 |
| --- | --- |
| 表ドラ | 局の開始時にめくる |
| 裏ドラ | リーチしてアガった人だけが見られる |
| カンドラ | カンが成立したらすぐ(即)めくる |
| カン裏 | カンドラの下の牌。リーチしてアガった人だけ |
| 赤ドラ | 赤い5は1枚につき1翻 |

## 4. リーチ

- 一発あり、ダブルリーチ(第一ツモ前のリーチ。2翻)あり。
- **フリテンリーチ可**:フリテンでもリーチできます(アガりはツモのみ)。
- **ツモ番のないリーチ可**:そのあと自分のツモ番が来なくてもリーチできます。ただし、海底牌(最後の牌)をツモった人はリーチできません。
- **リーチ後の暗槓**:面子の構成(手牌の分け方)が変わらない場合だけできます。待ちが変わる暗槓はできません。

## 5. フリテン

フリテンの状態ではロンできません(ツモアガリはできます)。

- **捨て牌フリテン**:自分の捨て牌に、当たり牌が1枚でもある。
- **同巡内フリテン**:当たり牌を見逃したら、次に自分がツモるまでロンできない。
- **リーチ後の見逃し**:リーチ後に当たり牌を見逃すと、その局はずっとロンできない。

## 6. ロンが重なったとき

- **ダブロン(2人同時のロン)はなし**。**頭ハネ**で1人だけがアガります。
- 優先順は、放銃した人から見て **下家(右隣)→ 対面 → 上家(左隣)**。

## 7. 流局

- **途中流局はなし**:九種九牌・四風連打・四家立直・四槓散了などで局を途中で終えることはありません。
- **ノーテン罰符**:場に合計3,000点。ノーテンの人がテンパイの人に支払います。

  | テンパイ人数 | ノーテン者の支払い | テンパイ者の受け取り |
  | --- | --- | --- |
  | 1人 | 1人あたり 1,000点 | 3,000点 |
  | 2人 | 1人あたり 1,500点 | 1人あたり 1,500点 |
  | 3人 | 3,000点 | 1人あたり 1,000点 |
  | 0人・4人 | 支払いなし | — |

- **形式テンパイ可**:役がなくても、形がテンパイならテンパイと認めます。
- ただし、**当たり牌を自分の手牌・副露ですべて使っている場合はノーテン**です(例:4枚目の牌を自分で持っている単騎待ち)。

## 8. 親と連荘

- **連荘**:親がアガる、または流局時に親がテンパイしていれば、親を続けます。
- **親流れ**:流局時に親がノーテンなら、次の人に親が移ります。子がアガった場合も親が移ります。
- **アガリやめの規定なし**:南4局で親がアガってもテンパイしても、トップでも自分から終えることはできません(連荘が続きます)。

## 9. 積み棒(本場)とリーチ棒(供託)

- **積み棒**:1本場につき300点(ロンなら放銃者が300点、ツモなら子3人が100点ずつ)。
  - 連荘したとき、**親ノーテンの流局でも**1本増えます。
  - 子がアガったら0本に戻ります。
- **リーチ棒**:リーチ時に出す1,000点は場に置かれ、**次にアガった人**がすべて受け取ります。
  - 南4局が流局で終わったら、場に残ったリーチ棒はトップの人が受け取ります。

## 10. 最終成績(ポイント)

半荘が終わったら、持ち点を次の式でポイント(pt)に直します(1,000点=1pt)。

> ポイント =(持ち点 − 30,000)÷ 1,000 + 順位点

| 順位 | 順位点 |
| --- | --- |
| 1位 | +50pt(+50,000点) |
| 2位 | +10pt(+10,000点) |
| 3位 | −10pt(−10,000点) |
| 4位 | −30pt(−30,000点) |

- 1位の+50には、30,000点返しによるオカ(+20)が含まれています。4人の合計はちょうど0ptになります。
- **同点**のときは、該当する順位の順位点を足して等分します(例:2位が2人なら (+10 −10) ÷ 2 = 0pt ずつ)。
- 例:1位で40,000点 → (40,000 − 30,000) ÷ 1,000 + 50 = **+60.0pt**

## 11. 符の計算

アガリの符は次の合計で、10符未満は切り上げます(七対子を除く)。

| 項目 | 符 |
| --- | --- |
| 副底(基本) | 20符 |
| 門前ロン | +10符 |
| ツモ | +2符(ピンフのツモは付かず20符) |
| 待ち:辺張・嵌張・単騎 | +2符(両面・双ポンは0符) |
| 雀頭:役牌(三元牌・自風・場風) | +2符(連風牌の雀頭も2符) |

面子の符:

| 面子 | 2〜8の牌 | 1・9・字牌 |
| --- | --- | --- |
| 明刻(ポンした刻子) | 2符 | 4符 |
| 暗刻 | 4符 | 8符 |
| 明槓 | 8符 | 16符 |
| 暗槓 | 16符 | 32符 |

特別な扱い:

- **ピンフのツモ**:20符。
- **鳴いたピンフ形のロン**(符が20符のままになる形):30符として扱う。
- **七対子**:25符2翻で固定(切り上げない)。

## 12. 点数

- 基本点 = 符 × 2^(翻数 + 2)。子のアガリは基本点×4、親のアガリは基本点×6(ロン)。ツモは分けて払い、それぞれ100点未満を切り上げます。
- **切り上げ満貫あり**:30符4翻・60符3翻(子7,700点/親11,600点になる手)は満貫として扱います。

| 名前 | 翻数 | 子 | 親 |
| --- | --- | --- | --- |
| 満貫 | 5翻(または基本点が2,000点以上) | 8,000点 | 12,000点 |
| 跳満 | 6〜7翻 | 12,000点 | 18,000点 |
| 倍満 | 8〜10翻 | 16,000点 | 24,000点 |
| 三倍満 | 11翻以上 | 24,000点 | 36,000点 |
| 役満 | 役満の役 | 32,000点 | 48,000点 |

- **数え役満なし**:13翻以上でも三倍満です。

## 13. 役

### 通常の役

| 翻数 | 役(カッコ内は鳴いたときの翻数。「門前」は鳴くと不成立) |
| --- | --- |
| 1翻 | 立直(門前)・一発(門前)・門前清自摸和(門前)・断么九・平和(門前)・一盃口(門前)・役牌(三元牌/自風/場風)・嶺上開花・搶槓・海底摸月・河底撈魚 |
| 2翻 | ダブル立直(門前)・七対子(門前)・三色同順(1)・一気通貫(1)・混全帯么九(1)・対々和・三暗刻・三色同刻・三槓子・小三元・混老頭 |
| 3翻 | 二盃口(門前)・純全帯么九(2)・混一色(2) |
| 6翻 | 清一色(5) |

### 役満

天和・地和・国士無双・四暗刻・大三元・緑一色・字一色・小四喜・大四喜・清老頭・四槓子・九蓮宝燈

- **緑一色**:發がなくても成立します。
- **異なる役満の複合はあり**(例:字一色+大三元 = 2倍役満)。
- **ダブル役満の別扱いはなし**:四暗刻単騎・国士無双十三面待ち・純正九蓮宝燈・大四喜などを、1つの役で2倍役満として扱うことはしません(公式の役一覧に別枠がないため)。
- **人和・流し満貫はなし**(公式の役一覧にないため)。

## 14. パオ(責任払い)

| 対象の役満 | 責任を負う人 |
| --- | --- |
| 大三元 | 3種類目の三元牌をポン/大明槓させた人 |
| 大四喜 | 4種類目の風牌をポン/大明槓させた人 |
| 四槓子 | 4つ目のカンを大明槓させた人 |

- **ツモ**:責任を負う人が全額を払います。
- **ロン**:放銃者と責任を負う人で半分ずつ払います(責任者本人の放銃なら全額)。
- **積み棒**:責任を負う人(鳴かせた人)が払います。

## 15. 搶槓

- 加槓(ポンした牌に4枚目を足すカン)に対する搶槓はあり。
- **暗槓に対する搶槓は不可**(国士無双でも不可)。
