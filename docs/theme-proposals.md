# デザイン3案(改善6)

`/dev/theme` で、ホーム・解説記事・何切るの見本を、案とライト/ダークを切り替えて見比べられます(スマホ幅/PC幅も切り替え可)。本番のページにはまだ使っていません。

## 3案共通

- 本文: **BIZ UDPゴシック**(読みやすさを重視したユニバーサルデザインフォント。@fontsource から読み込み)
- 見出しのフォントは案ごとに選ぶ
- 色・フォント・角丸・影はデザイントークン(`src/dev/themes.ts`)にまとめ、案の切り替えはトークンを CSS 変数として差し替えるだけ
- ライト・ダークの両方を用意し、文字と背景のコントラストはすべて WCAG AA 以上(`src/dev/themes.test.ts` で確認)
- 生成り色の背景と深緑のアクセントの組み合わせは使わない
- 牌の絵と赤5の目印は今のもの
- 練習メニューのカードは、牌の絵のアイコンを付け、最初にやってほしい「何切る」を大きくする

## 表示速度について

日本語フォントは重いので、@fontsource の日本語フォントは文字の範囲ごとに小さなファイルに分かれていて、ページで使う文字の分だけが読み込まれます。本番に適用するときは、本文フォントを太さ2種類(400・700)、見出しフォントを1種類に絞ります。
