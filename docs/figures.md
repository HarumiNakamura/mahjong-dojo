# 記事の図解

記事の文章で説明していた内容を図にしたものの一覧です(改善8)。

## しくみ

- 図は画像ファイルではなく SVG の部品(`src/components/figures/`)。牌は既存の牌の絵柄(`TileArt`)を使い、色はデザイントークン(`figures.css`)だけを使うので、ライト・ダークの両方に対応する
- `viewBox` の幅を 360 にそろえ、`width: 100%` で表示する(スマホで横にはみ出さない。PC では最大 480px)
- 題名と代替テキストは `src/content/figures.ts`。記事では `@figure <id>` と書く
- 図全体を `role="img"` と `aria-label`(代替テキスト)で1枚の画像として読み上げる。代替テキストだけで図の要点がわかる文にする
- 記事の冒頭の「この記事でわかること」は `@points` の次の行から `- ` で3行、最後は `## まとめ` と3〜5行の箇条書き(`articles.test.ts` で確認)

## 確認したこと

- 幅360px のスマホ表示とライト・ダークの両方で、全部の図を撮影して確認(横スクロールなし)
- スジの図:4が現物のとき、1と7の両面待ち(23・56)だけが消え、嵌張・シャンポン・単騎には当たることを明記
- 壁の図:8萬が4枚見えると78萬の両面(6・9萬待ち)が作れず、9萬はノーチャンス
- 符の図:記事の例2(リーチ・東場・東の雀頭・7筒の暗刻・6索の両面ロン)。副底20+門前ロン10+暗刻(中張牌)4+雀頭(場風)2=36符 → 40符。連風牌の雀頭も2符(docs/rules.md)
- 半荘の図:アガリやめなしのため、南4局でも親のアガリ・テンパイなら連荘が続く(docs/rules.md)
