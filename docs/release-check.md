## 5. 誤字・rules.md との食い違い

- UI と記事の文章から、ルールと食い違いやすい表現(連風牌の雀頭4符・ダブロンあり・途中流局あり・流し満貫・人和・数え役満・トビ・西入・喰い替え可・フリテンリーチ不可・ノーテン罰符の額)を検索し、**食い違いはなし**
- 同じ言葉が重なる誤字(「のの」「をを」「。。」など)の検索で**誤字なし**
- 用語の表記はおおむね統一(アガリ・シャンテン・テンパイ・放銃・雀頭)。「和了率」(押し引きの解説)、「聴牌気配」(記事名)は意図して使っている

## 6. 残っている課題(大きめのため今回は直していない)

1. **公開前に書き込む情報**:`src/app/siteInfo.ts` の運営者名・お問い合わせフォームの URL・Google 広告設定の URL が空(画面では「準備中」と表示)。
2. **広告**:AdSense の審査が通ったあと、広告コードと `ads.txt` の設置が必要。
3. **ページの題名の表記ゆれ**:ビルド時の HTML の題名(例:「牌効率」)と、ページを開いたあとのタブの題名(例:「何切る(牌効率)」)が一部のページで違う。どちらかにそろえるとよい。
4. **局の精算のエンジン**:頭ハネ・パオ・順位点などはエンジンにない。オーラスの判断のドリルなどを作るときに必要になる。
5. **表示速度の本番での計測**:Lighthouse は手元のプレビューで計測した(`docs/performance.md`)。公開後に本番の URL でも計測するとよい。

7. **今回の確認で通しで試していないもの**:点数計算の中級・上級、待ち当てのタイムアタック、学習記録の書き出し・読み込み(いずれも作ったときに確認済み)。
