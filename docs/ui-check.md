# スマホでの手牌の操作性(確認記録)

改善1(手牌の大きさと2段階タップ)の確認結果です。Chromium で画面幅 360・390・430px を開き、手牌1枚の大きさと押せる範囲を測りました(2026-10-20)。

## 決めたこと

- 手牌から選ぶ画面の手牌(`Hand` の `full`。`onPick` を渡すと既定でオン)は、本文の余白をはみ出して **画面幅いっぱい(左右4px)** に1列で並べる。PC では最大560px
- 牌の間隔は0、ツモ牌は4px離す
- 押せる範囲(ボタン)は **高さ44px以上**(牌が小さくても下側まで押せる)
- 有効牌の一覧の牌は最大20pxにして、手牌より小さくする
- 安パイ並べの並べ替えも同じ幅いっぱいの並べ方にする(7列×2段)
- 手牌から1枚選ぶ画面はすべて **2段階タップ**(1回目で選んで少し持ち上げる → 同じ牌をもう一度タップか「◯◯を切る」ボタンで決定)。手牌の下の「1回のタップで決定する」で元の操作に戻せる(設定はブラウザに保存し、全画面で共通)
