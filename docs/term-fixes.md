# 用語部品の適用と用語の直し(改善3)

記事やドリルの用語を、用語部品(`src/components/term/Term.tsx`)でタップして確かめられるようにしました。用語のデータは `src/content/terms.ts` です。

## 決めたこと

- 各記事で、用語が**初めて出てくる箇所だけ**を用語部品にする(`{{面子}}` と書く)。2回目以降と見出しの中はそのまま
- 初めて出てくる漢字だけの用語には読み仮名を付ける(例: `{{七対子}}(チートイツ)`)。すでに読みや説明の括弧がある場合は付けない
- 「待ち」「受け入れ枚数」「押し引き」のように、読みが自明な言葉やかなを含む言葉には読みを付けない
- 1文字で別の意味にもなる言葉(子・山・頭 など)は自動では用語部品にしない

## 説明より先に用語を使っていた箇所の直し

| 記事・画面 | 直したこと |
| --- | --- |
| 麻雀の基本の流れ | 牌の説明(赤い5)で「1翻」が翻の説明より前に出ていた → 赤い5は「点数が上がる」とだけ書き、「アガリの形」の節で翻(ハン)を説明してから「一翻縛り」「ドラ・赤5は1翻」を説明する順に変更 |
| 現物・スジ・壁 | 「引っかけ」に説明がなかった → スジでも嵌張・シャンポン・単騎には当たることと、引っかけ(4萬を切ったあと68萬の嵌張で7萬を待つ例)を追加。宣言牌の意味も追加 |
| 何切るの結果表 | 「戻し」に説明がなかった → 「戻し」「シャンテン数」「受け入れ」「有効牌」を用語部品に |
| そのほかの記事 | 各記事で最初に出てくる用語をすべて用語部品にしたので、説明より先に出てくる用語もその場で確かめられる |

## ドリル・CPU対戦・学習記録の画面

- 何切る: 結果表の見出し(シャンテン数・受け入れ)・「戻し」・有効牌、ヒントの「受け入れ」
- 一人麻雀の振り返り: 受け入れの差
- 安パイ並べの解説: 現物・字牌・スジ・壁・無スジ
- 鳴き判断の解説: シャンテン数
- CPU対戦の振り返り・通算成績、学習記録: 放銃率・副露率
