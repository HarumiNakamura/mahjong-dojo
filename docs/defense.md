# 守備の判定(安全度の根拠と危険度の目安)

守備のドリル(安パイ並べ・ベタオリサバイバル)と押し引きの判定は、`src/engine/danger.ts` で牌の安全度を判定しています。
危険度の数値は `src/data/danger-table.ts` の1か所にまとめています。

## 1. 判定の順番

リーチ者1人に対して、牌の種類ごとに次の順で根拠を決めます。

| 順 | 根拠 | 内容 |
| --- | --- | --- |
| 1 | 現物 | リーチ者の河にある牌(フリテンなのでロンできない)。リーチ後に他家が切って通った牌(見逃すとフリテンになる) |
| 2 | 字牌 | 自分から見えている枚数(自分の手牌・全員の河・ドラ表示牌)で危険度を分ける。字牌は両面待ちにならない |
| 3 | スジ | 両面待ちで当たる形が、すべて「もう片方が現物」で消えている。1・2・3 は 4・5・6、7・8・9 は 4・5・6 の現物が根拠 |
| 3 | 両スジ | 4・5・6 で、両側ともスジ(例: 2 と 8 が現物の 5) |
| 3 | 宣言牌のスジ | スジの根拠がリーチ宣言牌だけのとき。引っかけ・シャンポンが残りやすいので、スジより少し危険 |
| 4 | ノーチャンス(壁) | 両面待ちに必要な牌が4枚見えていて、その両面待ちがない(残りの形はスジで消えていてもよい) |
| 5 | ワンチャンス | 両面待ちに必要な牌が残り1枚 |
| 6 | 片スジ | 4・5・6 で、片側だけスジまたは壁 |
| 7 | 無スジ | 上のどれにも当たらない数牌 |

スジ・壁で消えるのは「両面待ち」だけです。嵌張・辺張・シャンポン・単騎には当たることがあるので、危険度は0になりません。

## 2. 危険度の目安(リーチ者1人、%)

よく知られた統計(リーチに対する、牌の種類ごとの放銃率)をもとにした概算です。巡目・河の様子・ドラなどによる違いは入れていません。

| 根拠 | 1・9 | 2・8 | 3・7 | 4・5・6 |
| --- | --- | --- | --- | --- |
| 現物 | 0 | 0 | 0 | 0 |
| スジ | 2.5 | 3.5 | 4.5 | ― |
| 両スジ | ― | ― | ― | 3.5 |
| 宣言牌のスジ | スジ × 1.3 | | | 両スジ × 1.3 |
| ノーチャンス | 2.0 | 3.0 | 4.0 | 5.0 |
| ワンチャンス | 4.5 | 6.0 | 7.0 | 9.0 |
| 片スジ | ― | ― | ― | 7.5 |
| 無スジ | 6.0 | 8.0 | 9.5 | 12.0 |

字牌は見えている枚数で、3枚見え 0.5・2枚見え 2.0・1枚見え 4.0・0枚(生牌)6.0 です。

数値の考え方:

- 無スジの真ん中(4・5・6)は両側の両面待ちに当たるので一番危険、端(1・9)ほど安全。
- スジの 1・9 はシャンポン・単騎だけ、2・8 は嵌張も、3・7 はさらに辺張にも当たるので、端ほど安全。
- 字牌は見えている枚数が多いほど、シャンポン待ちの可能性が減る。生牌の字牌はスジの3・7程度、2枚見えはスジの1・9より安全。
- ノーチャンスは「両面待ちがない」点ではスジに近いが、リーチ者が嵌張・シャンポンで同じ牌を使っている可能性があるので、スジと同じかやや安全程度にしている。

## 3. リーチ者が複数のとき

リーチ者ごとの危険度を p1, p2 として、全員に通る確率 (1 − p1)(1 − p2) から、まとめた危険度を 1 − (1 − p1)(1 − p2) とします。
どちらかに無スジなら、もう片方に現物でも危険度は残ります。

## 4. 練習用の局面の作り方

1. 山から4人に配牌し、4人とも何切るドリルと同じ判定(牌効率)で打ちます。
2. 自分以外がテンパイしたらリーチします(予定の人数まで)。リーチ後はツモ切りです。
3. リーチ者に当たる牌を誰かが切った局・ツモアガリが出た局は使いません。
4. リーチがかかって1巡以上たったところで、自分のツモ番の局面を問題にします。リーチ者の手牌は答え合わせに使います。

## 5. 注意

- 危険度はあくまで目安です。実際には巡目・河の切り順・ドラ・相手の打点で大きく変わります。
- 「現物」以外の牌は、どれも当たることがあります。
